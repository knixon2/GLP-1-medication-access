# GLP-1-medication-access
Data from the manuscript "Uncovering the gray side of GLP-1 medication access: an LLM-based information extraction pipeline"

LLM_labels_monthly_counts.xslx: monthly counts for each LLM label
Platforms_analysis_monthly_counts.xslx: monthly counts for each label from the platforms analysis
Specific_platforms_monthly_counts.xslx: monthly counts for each platform's mentions
Platform_to_type_label_mapping.xslx: mapping from platform name to platform type/label
